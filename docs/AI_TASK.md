## 目的
TikTokアフィリエイト用の仕組みを、本番の日次運用で安定して使える状態へ仕上げる。
ユーザーへの途中確認は不要。ChatGPT が仕様・レビューを担当し、Claude Code が実装・テスト・PR作成を担当する。

## 今回の重点タスク
1. `CLAUDE.md` とこの `docs/AI_TASK.md` を読む。
2. `main` の最新状態を基準に、TikTok日次生成の「本番運用上の穴」を監査する。
3. 特に以下を確認し、問題があれば安全に修正する。
   - `data/tiktok_history.json` が GitHub Actions の日次実行をまたいで確実に保持・更新され、前回選定商品の重複防止が翌日以降も実際に効くこと
   - `src.tiktok_daily` が生成した `tiktok/daily_content.json` / `tiktok/daily_content.md` と履歴が矛盾なく同じ実行内で更新されること
   - GitHub Actions が生成物だけを安全にコミットし、秘密情報や不要ファイルを含めないこと
   - 同じ日に手動再実行しても履歴破損や不自然な二重記録が起きにくいこと
   - 候補0件・API失敗・生成失敗時に、Actions Summary/ログから原因を初心者でも判断しやすいこと
   - iPhone向け `tiktok/index.html` が最新の生成データを正しく表示し、商品名・台本・テロップ・キャプション・ハッシュタグをコピーしやすいこと
4. 実データや秘密情報を使わずに、上記の重要な流れを再現できる自動テスト/統合テストを追加する。
5. 問題が見つからなければ、無理な変更はせず、確認結果と本番運用上の残課題だけを記録する。
6. 既存の楽天ROOM機能を壊さない。
7. TikTok/楽天ROOMへの自動投稿・自動ログイン・自動購入は実装しない。
8. 課金が必要な外部サービスや動画生成APIを勝手に追加・有効化しない。
