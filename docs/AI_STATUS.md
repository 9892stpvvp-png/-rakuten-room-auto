## 1. 根本原因

1. 新しい商品タイプ（アロマスプレー・ドッグフード・ヤギミルク・スワドル/おくるみ・おむつペール・おむつストッカー）がPRODUCT_TYPE_TEMPLATES未登録で、汎用文になっていた。
2. 「アロマスプレー」商品のタイトルに「アロマオイル」「精油」という関連語（原材料上の関連語）が含まれていたため、商品本体（スプレー）ではなく関連語の方でアロマオイル用テンプレートが誤って選ばれていた。
3. 「おむつペール」「おむつストッカー」商品のタイトルに、description-genre-004で意図的に汎用的な最後の保険として登録した「オムツ」が含まれていたため、実際はゴミ箱・収納用品である商品が紙おむつ用テンプレートで紹介されていた。既存の出現位置優先判定は、同程度に具体的なキーワード間（サーキュレーター・扇風機等）では機能するが、汎用キーワードと具体的な複合語の間の優先順位までは考慮していなかった。
4. 「100g 500g 1000g」のように、同じ単位の数値が複数並ぶ商品名（＝内容量の選択肢）から、最初の値だけを固定サイズとして抜き出していた。

## 2. 商品本体判定をどう改善したか

`_iter_product_type_keyword_matches()`に、キーワードの「具体性」による優先度を追加した。「オムツ」「うどん」は意図的に汎用的な最後の保険として登録したキーワードであるため、`_GENERIC_FALLBACK_PRODUCT_TYPE_KEYWORDS`という明示的な集合に登録し、商品名の中で他の（より具体的な）商品タイプキーワードが1つでも見つかった場合は、登場位置に関わらずそちらを優先するようにした。これにより「おむつペール」「おむつストッカー」という具体的な複合語が「オムツ」という汎用語より優先されるようになった。

「アロマスプレー」「マスクスプレー」は、当該商品のタイトルで実際にこれらの語が「アロマオイル」「精油」より先に登場するため、既存の出現位置優先判定（description-genre-004）だけで正しく解決できた。本物のアロマオイル商品（「アロマスプレー」を含まない）まで誤ってスプレー扱いされないよう、既存のアロマオイル系キーワードは変更していない。

この設計により、「①具体的な複合商品名 → ②商品本体を表す名詞（意図的な汎用キーワードより優先） → ③ジャンル別安全テンプレート → ④安全フォールバック」という優先順位が実現された。

## 4. 数量/サイズ選択肢の改善

`_QUANTITY_PATTERNS`の最優先パターンとして、同じ単位の数値が空白区切りで複数（2〜5個）並ぶ表記（例：「100g 500g 1000g」）を1つのまとまりとして抜き出すパターンを追加した。`_phrase_for_size_options()`を新設し、このパターンに一致する場合は「100g・500g・1000gから選べる」という、選択肢であることが伝わる言い回しにした（最初の値だけを固定サイズと誤認させない）。数値と数値の間に単位以外の語が入らない、空白だけで区切られた並びに限定しているため、無関係な数値を誤ってサイズ候補として扱うリスクは低い。

また、「よりどり」を`_VARIETY_COUNT_INDICATOR_WORDS`に追加した。「複数の選択肢から好きなものを選ぶ」ことを表す一般的な販売表現であり、「選べる」「種類」と同様に安全に使える判定語のため。
