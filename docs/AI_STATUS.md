## 1. 根本原因

1. 新しい商品タイプ（ヒップシート・ミルクウォーマー・車用サンシェード・そば・折りたたみ傘・ほこり取りスポンジ）がPRODUCT_TYPE_TEMPLATES未登録だった。ヒップシートは「おしりふき」（収納できる持ち物の一例）に誤って一致し、車用サンシェードはファッションの汎用文になり、ほこり取りスポンジは「スポンジ」という一般語に一致して食器洗い用テンプレートで紹介されていた。
2. 数字＋kg/g/cm等を見つけただけで、常に「重さは約○kg」「サイズは約○cm」と生成していた。ヒップシート「20kg」は対応体重等の可能性があるのに商品重量として断定していた。逆に、折りたたみ傘「260g超軽量」は、単位の直後が漢字（「超」）のためUnicode正規表現の単語境界（\b）が成立せず、既存の単独パターンでは抽出すらできていなかった。
3. GENERIC_TEMPLATESに「ペット用品」カテゴリーの安全な汎用テンプレートが存在せず、PRODUCT_TYPE_TEMPLATESに一致しないペット用品はDEFAULT_CATEGORY（「暮らし全般」）の完全に汎用的な文言に落ちていた。

## 3. 数値・重量判定の改善内容

1. 「kg」単位は、周辺（前後12文字）に「重量」「重さ」「軽量」「超軽量」「わずか」のいずれかが無い限り、商品自体の重さとして確認できたと判定しないようにした（`_is_confirmed_kg_weight()`を新設）。「g」単位は実務上ほぼ常に商品自体の重さを指すため対象外。確認できる根拠が無い数値は安全側に倒して省略する。
2. 単位の直後に「軽量」「超軽量」が続く場合（例：「260g超軽量」）を、境界（\b）を要求しない専用パターンで抽出できるようにした（単位の直後が漢字だとUnicode正規表現の単語境界が成立せず、既存パターンでは抽出できなかった実装上の制約を解消）。
3. 「◯人前」の単独表記（重さ/個数の組み合わせを伴わない場合）にも対応した（例：「6人前」）。
4. 「計◯枚」のような合計表記が複合数量表記の末尾に付いている場合（例：「54枚×15個 計810枚」）、合計も一緒に抜き出し、「54枚入り×15個・計810枚」という自然な言い回しにした。「計」を必須にすることで、合計表記の無い通常の複合表記（例：「80枚×40個」）を誤って分割しないようにしている。

## 4. ペット用品フォールバックの改善

`GENERIC_TEMPLATES`に「ペット用品」の安全な汎用テンプレートを新設した。「愛犬・愛猫のお世話に使いやすいペット用品」という、category="ペット用品"という確認済みの情報だけを使った言い回しで、ドッグフード・おもちゃ等の具体的な商品タイプは一切断定しない。これにより、商品名だけからは具体的な商品タイプを確定できない商品（サイエンス シニア小粒、サンジョルディ たまごちゃん等）でも、暮らし雑貨ではなくペット用品として適切に紹介されるようになった。
