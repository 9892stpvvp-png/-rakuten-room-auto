## 根本原因

6件それぞれの原因は次のとおり（詳細は`docs/DESIGN.md`32章参照）。

1. **コードレスクリーナースタンド**（`bathroom:10002371`）：「クリーナースタンド」は掃除機本体ではなく、掃除機を収納するスタンドだが、`PRODUCT_TYPE_TEMPLATES`に該当キーワードが無く、`CATEGORY_NAME_KEYWORDS["掃除"]`の「クリーナー」判定経由で`GENERIC_TEMPLATES["掃除"]`（掃除機本体向けの汚れお手入れ文言）にフォールバックしていた。
2. **ボール・コランダーセット**（`risu-onlineshop:10002060`）：`FEATURE_CLAUSES`の「フタ付き」節が「フタ付きでホコリを防ぎやすい」となっており、確認できる「フタが付いている」という構造の事実を超えて、確認できない「ホコリを防ぐ」目的・効果まで断定していた。
3. **スターフィルター**（`starfilter:10000019`）：レンジフード・換気扇用フィルターという具体的な商品タイプが`PRODUCT_TYPE_TEMPLATES`に無く`GENERIC_TEMPLATES["キッチン"]`にフォールバックしていた。加えて`FEATURE_CLAUSES`の「一人暮らし」節（広告用の対象者向け販売キーワード）が✔️メリットの主要項目に採用されていた。
4. **川根茶**（`katayamaen:10000442`）：数量抽出が「500mlペットボトル茶**50本分**が作れる」から「50本」だけを抜き出し、実際の内容量（個包装0.8g×50）とは異なる「50本入り」のような誤解を招く表記になっていた。
5. **finish 食洗機用洗剤**（`good-item:10000868`）：`DETERGENT_SUBTYPE_TEMPLATES`の「食器」キーワードが「食器洗い機用洗剤」「食器洗浄機用」にも一致し、手洗い用テンプレート（「普段の食器洗いに使いやすい」）が使われていた。
6. **木村石鹸 トイレタンクの洗浄剤**（`kimurasoap:10000017`）：「トイレタンク」という具体的な商品タイプが`PRODUCT_TYPE_TEMPLATES`に無く、カテゴリー「日用品」の汎用テンプレートにフォールバックし、「トイレタンク」「つけおき」「除菌」という固有情報が反映されていなかった。

## 修正内容（優先順位に沿って実施）

個別商品のitem_codeをハードコードするのではなく、既存の判定インフラ（`PRODUCT_TYPE_TEMPLATES`・`DETERGENT_SUBTYPE_TEMPLATES`・`FEATURE_CLAUSES`・`_extract_quantity_phrase`）をキーワードベースで拡張した。優先順位は「1. 具体的な商品タイプ → 2. ○○用など対象用途 → 3. 商品固有の確認済み特徴 → 4. 数量・容量・セット内容 → 5. 細カテゴリー（今回変更せず）→ 6. 大カテゴリー汎用テンプレート」の順。

- `PRODUCT_TYPE_TEMPLATES`に4件追加：クリーナースタンド・レンジフードフィルター・換気扇フィルター・トイレタンク。
- `DETERGENT_SUBTYPE_TEMPLATES`に`_DISHWASHER_DETERGENT_TEMPLATE`（食洗機用）を追加し、「食洗機」「食器洗い機」「食器洗浄機」を手洗い用の「食器」キーワードより先に判定するようにした。
- `FEATURE_CLAUSES`の「フタ付き」「蓋付き」を「フタ付きで使いやすい」（構造の事実のみ）に修正。
- `FEATURE_CLAUSES`に「耐熱」「タブレット」を追加し、フタ付きより先に判定するよう並び順を調整（より情報量の多い確認済み仕様を優先）。
- `FEATURE_CLAUSES`から「一人暮らし」を削除（商品本体の仕様ではなく広告用の対象者向けキーワードのため）。
- `_extract_quantity_phrase()`に「ラベル付き個数を+でつないだ表記（例：枠2枚+フィルター4枚）」「末尾に単位の無い重さ/容量×個数表記（例：0.8g×50）」のパターンを追加。
- `_QUANTITY_MATCH_EXCLUDE_SUFFIX`に「分」を追加し、「50本分」等を実際の個数と混同しないようにした。

すべて商品名のキーワード・正規表現による汎用的な判定であり、今回の10件に限らず将来の商品にも適用される。`refine_category`・`CATEGORY_NAME_KEYWORDS`・`ranking.py`・`dedupe.py`・`data/posted_items.json`は一切変更していない。

## 残っている制約

- `DETERGENT_SUBTYPE_TEMPLATES`（「○○用」の判定）は現状「洗剤」カテゴリーにしか適用されない。他のカテゴリーで同種の用途誤認が見つかった場合、同じ仕組みを拡張する余地がある。
- `FEATURE_CLAUSES`による✔️メリットの3項目目は、商品名から複数の確認済み特徴が同時に読み取れる場合でも最初に一致した1件だけを採用する（既存の設計を維持）。例えばボール・コランダーセットは「耐熱」「電子レンジ対応」「食洗機対応」「フタ付き」のうち「耐熱」だけが反映される。
