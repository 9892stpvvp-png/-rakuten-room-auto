# 楽天ROOM自動化プロジェクト

「暮らしの便利グッズ」をテーマに、楽天ROOMへ投稿する商品候補探しから紹介文づくりまでを
自動化するためのプロジェクトです。プログラミング初心者の方でも進められるよう、
専門用語をできるだけ避けて説明しています。

## これは何をするプロジェクト？

やること（自動化する部分）：

1. 楽天の公式データを使って、掃除・収納・キッチン用品・時短グッズなどの
   「暮らしの便利グッズ」と、洗剤・キッチン消耗品・トイレットペーパーなどの
   日用品、水・お茶・ジュースなどの飲料（「消耗品・飲料」）の商品候補を集める
2. 「レビュー評価4.0以上」「レビュー件数100件以上」などの条件で絞り込む
3. 過去に紹介した商品と重ならないかチェックする
4. 楽天ROOMの紹介文欄にそのままコピペできる文章（絵文字入り・500文字以内）を自動で作る
5. 「暮らしの便利グッズ」5件＋「消耗品・飲料」5件（合計最大10件）のバランスで
   候補一覧を保存する（片方が5件に満たない場合だけ、もう片方から補充する）

やらないこと（自動化しない部分）：

- 楽天ROOMへの**自動投稿**は行いません。楽天ROOMの利用規約で「機械的な投稿」が禁止されているためです。
  最後にコピペして投稿するのは人間（あなた）が行います。
- 楽天ROOMへの自動ログインや、ROOMサイトの自動操作（スクレイピング）も行いません。

**なぜ自動投稿しないのか**など、詳しい調査結果と設計の理由は
[docs/DESIGN.md](docs/DESIGN.md) にまとめてあります。プロジェクトの背景を知りたい方は先にこちらをご覧ください。

## 全体の流れ（イメージ）

```
商品候補を集める → 条件で絞り込む → 重複を除く → 紹介文を作る → 候補一覧を保存
                                                                      ↓
                                                    人間が内容を確認して、手動でROOMに投稿
```

## 使う技術・仕組み

- 商品データの取得には、楽天が公式に提供している「楽天ウェブサービス（Rakuten Web Service）」の
  商品検索APIを使います。合言葉のような「アプリID」と「アクセスキー」を無料で発行してもらう必要があります。
- プログラムはPython（プログラミング言語のひとつ）で作られています。GitHub Actionsを使えば、
  自分のパソコンにPythonを入れなくても実行できます（詳しくは後述）。

## セットアップ（準備）

1. Python がインストールされていない場合はインストールしてください（バージョン3.10以上を推奨）。
2. このリポジトリをダウンロード（クローン）します。
3. 必要なライブラリをインストールします。

   ```bash
   pip install -r requirements.txt
   ```

4. `.env.example` をコピーして `.env` という名前のファイルを作り、
   楽天ウェブサービスで発行した「アプリID」を書き込みます。

   ```bash
   cp .env.example .env
   ```

   `.env` ファイルは絶対にGitHubなどに公開しないでください（`.gitignore` で自動的に除外されます）。

5. `config/settings.example.yaml` を参考に、検索したいキーワードや条件を調整します。
   - `keywords`：検索キーワードと、どちらの枠の商品か（`group`：
     `convenience`=暮らしの便利グッズ／`consumable`=消耗品・飲料）、
     そのキーワードのカテゴリ（`category`）をセットで指定します。
     便利グッズ枠は「掃除／収納／キッチン／時短／暮らし全般」、
     消耗品・飲料枠は「洗剤／キッチン消耗品／日用品／水／お茶／ジュース」の
     いずれかです。カテゴリは紹介文の言い回しを選ぶのに使われます。
   - `ng_keywords`：商品名・説明に含まれていたら除外する言葉（福袋・ランダム・訳ありなど）です。
   - `off_theme_keywords`：商品名・説明に含まれていたら除外する言葉（耳かき・財布・アクセサリー
     など、テーマから明らかに外れるジャンル）です。
   - `alcohol_keywords`：飲料カテゴリ（水／お茶／ジュース）の商品のうち、
     ビール・チューハイ・ワインなどアルコール飲料とみられる商品を除外する言葉です。
   - `similarity_threshold`：同じカテゴリ内で「用途がほぼ同じ類似商品」とみなす商品名の
     類似度のしきい値です（似た商品が複数上位に並ぶのを防ぎます）。
   - `convenience_target` / `consumable_target`：毎日の候補のうち、それぞれの枠から
     何件選ぶか（初期設定は5件ずつ）です。
   - `summary_max_per_category`：「暮らしの便利グッズ」枠5件のうち、同じカテゴリが
     連続して入ってよい最大件数です（上位が1カテゴリに偏るのを防ぎます）。
   - `consumable_max_per_category`：「消耗品・飲料」枠5件のうち、同じカテゴリが
     連続して入ってよい最大件数です（水だけ・洗剤だけに偏るのを防ぎます）。

## GitHub Actionsで実行する方法（おすすめ）

自分のパソコンにPythonを入れなくても、GitHub上のボタン操作だけで商品候補の検索を実行できます。

### 事前準備：Repository Secretsの登録（登録済みの場合はこの手順は不要です）

1. GitHubでこのリポジトリを開き、上部の **「Settings（設定）」** タブを開きます。
2. 左側メニューの **「Secrets and variables」→「Actions」** を開きます。
3. 「New repository secret」から、以下の2つを登録します（すでに登録済みならこの手順は不要です）。
   - `RAKUTEN_APP_ID` … 楽天ウェブサービスの「アプリID」
   - `RAKUTEN_ACCESS_KEY` … 楽天ウェブサービスの「アクセスキー」

   > Secretに登録した値は、GitHub上でも他の人からも見えません。このプロジェクトのコードやログにも
   > 表示・保存されないようになっています。

4. `config/settings.yaml`（無ければ`config/settings.example.yaml`をコピーして作成）の
   `allowed_origin` を、楽天ウェブサービスのアプリ設定で登録した
   「アプリケーションURL」「許可されたWebサイト」と**まったく同じ値**にしてください。
   （2026年の仕様変更により、ここが一致していないとHTTP 403エラーになります。）

### 実行方法

1. 上部の **「Actions」** タブを開きます。
2. 左側の一覧から **「商品候補を検索する」** を選びます。
3. 右側に出てくる **「Run workflow」** ボタンを押し、そのまま緑色の **「Run workflow」** をクリックします。
4. 数十秒〜数分待つと実行が完了します（一覧に緑色のチェックマークが付きます）。
5. 完了した実行をクリックすると、ページの上の方に **候補一覧がそのまま表示されます**
   （これを「Summary」と呼びます）。スマートフォンでもZIPをダウンロードせずにここで確認できます。
   商品名・価格・レビュー評価・件数・商品URL・紹介文が上位10件ほど表示されます。
6. 全件をまとめて見たい・データとして使いたい場合は、ページ下の方にある
   **「Artifacts（成果物）」** の `rakuten-room-candidates` からダウンロードできます
   （`candidates_日時.md` が全件入りの一覧、`candidates_日時.json` がデータ用です）。

### 毎日自動で実行される仕組み

手動で「Run workflow」を押さなくても、**毎日1回、日本時間15:30**に自動で
商品候補検索が実行されます（`.github/workflows/run_scheduled_search.yml`）。

- cronは1日1回しか予定時刻に一致しないため、同じ日に自動実行が重複することは
  ありません。
- 手動での「Run workflow」（上の「実行方法」）は、この自動実行とは関係なく
  いつでもすぐに実行できます。

### スマホから投稿できる専用ページ

毎日の検索結果（「暮らしの便利グッズ」5件＋「消耗品・飲料」5件、合計最大10件）を、
スマートフォンから短時間で楽天ROOMへ投稿しやすい形で確認できる専用ページを
用意しています。

**<https://9892stpvvp-png.github.io/-rakuten-room-auto/room/>**

このURLをiPhoneのSafariでブックマークしておくと、Artifactをダウンロード
したり候補一覧ファイルを開いたりしなくても、毎日15:30の自動実行後に
この固定URLを開くだけで最新の候補を確認できます。ページ上部には
「内訳：便利グッズ5件 / 消耗品・飲料5件」のような内訳も表示されます。

- 1商品＝1枚のカードで、「便利グッズ／消耗品／飲料」の小さなカテゴリ表示・
  商品画像・商品名・価格・レビュー評価/件数・紹介文全文を表示します
- 「紹介文をコピー」：生成済みの紹介文をそのままクリップボードにコピーします
- 「楽天市場からROOM投稿へ」：APIから取得した正式な商品URL（楽天市場の商品ページ）
  をそのまま開きます。楽天市場の商品ページには公式に「ROOMに投稿する」が
  用意されているため、ボタンの下に「楽天市場の商品ページで『ROOMに投稿する』を
  タップ」と案内しています（スマホ投稿ページ→楽天市場の商品ページ→
  「ROOMに投稿する」→ROOMの投稿画面、という最短導線）
- 「ROOM検索ワードをコピー」：商品ページに「ROOMに投稿する」が表示されない
  場合の予備手段として、商品名をクリップボードにコピーします（ROOM内の検索で
  貼り付けて投稿する用）
- 「商品URLをコピー」：商品URLをクリップボードにコピーします
- 「投稿済みにする」：カードを投稿済み表示にします（この端末のブラウザの
  localStorageに保存されるだけで、GitHubや楽天側には書き戻されません）
- 「未投稿のみ表示」：投稿済みを除いた商品だけを表示します

ページのデータ（`room/data/candidates.json`）は、毎日の商品候補検索
（`search_candidates.yml`）が成功するたびに自動で最新化されます。

### うまくいかない場合（HTTP 403などのエラー）

実行結果が赤い×印になった場合は、Actionsの実行ログを開くとエラーメッセージが表示されます
（秘密情報は表示されない設計なので、ログをそのまま見て問題ありません）。

- **HTTP 403** が出る場合は、`allowed_origin`（上の「事前準備」の4番）が
  楽天ウェブサービス側の「許可されたWebサイト」と完全に一致しているかを確認してください。
- そのほかのエラーの詳しい原因と対応方法は
  [docs/DESIGN.md](docs/DESIGN.md) の「HTTP 403エラーが出た件について」にまとめてあります。

### 自分のパソコンで実行する場合

```bash
python -m src.main
```

`.env`ファイルに `RAKUTEN_APP_ID` と `RAKUTEN_ACCESS_KEY` を設定していれば、
`data/candidates/` フォルダに同じ形式の結果ファイルが作られます。

### テスト（開発者向け）

紹介文生成に問題がないかを確認する自動テストがあります（楽天APIへのアクセスは不要）。

```bash
python -m unittest discover -s tests -v
```

### 投稿した後にやること

候補一覧の中から実際に楽天ROOMへ投稿した商品があれば、`data/posted_items.json` の
`posted_item_codes` にその商品コード（`item_code`）を追記してください。
次回の検索から、その商品は候補に出てこなくなります（重複防止）。

## 大事な注意事項

- このプロジェクトは楽天ROOMへの**自動投稿を行いません**。生成された紹介文の最終確認と投稿は、
  必ず人間が行ってください。
- 楽天ウェブサービスの「アプリID」「アクセスキー」は大事な秘密情報です。他人に教えたり、
  コード・README・ログ・GitHub Pagesなどに書き込んだりしないでください。
  このプロジェクトではGitHubの Repository Secrets（暗号化された保管場所）にのみ保存し、
  実行結果のファイルにも値が出力されないようにしています。
- 楽天の利用規約は変更されることがあります。運用を始める前に、最新の
  [楽天ROOM利用規約](https://room.rakuten.co.jp/signup/agreement) を確認することをおすすめします。
