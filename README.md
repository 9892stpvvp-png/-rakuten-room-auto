# 楽天ROOM自動化プロジェクト

「暮らしの便利グッズ」をテーマに、楽天ROOMへ投稿する商品候補探しから紹介文づくりまでを
自動化するためのプロジェクトです。プログラミング初心者の方でも進められるよう、
専門用語をできるだけ避けて説明しています。

## これは何をするプロジェクト？

やること（自動化する部分）：

1. 楽天の公式データを使って、掃除・収納・キッチン用品・時短グッズなどの商品候補を集める
2. 「レビュー評価4.0以上」「レビュー件数100件以上」などの条件で絞り込む
3. 過去に紹介した商品と重ならないかチェックする
4. 楽天ROOMの紹介文欄にそのままコピペできる文章（500文字以内）を自動で作る
5. できあがった候補を一覧として保存する

やらないこと（自動化しない部分）：

- 楽天ROOMへの**自動投稿**は行いません。楽天ROOMの利用規約で「機械的な投稿」が禁止されているためです。
  最後にコピペして投稿するのは人間（あなた）が行います。
- 楽天ROOMへの自動ログインや、ROOMサイトの自動操作（スクレイピング）も行いません。

**なぜ自動投稿しないのか**など、詳しい調査結果と設計の理由は
[docs/DESIGN.md](docs/DESIGN.md) にまとめてあります。プロジェクトの背景を知りたい方は先にこちらをご覧ください。

## 全体の流れ（イメージ）

```
商品候補を集める → 条件で絞り込む → 重複を除く → 紹介文を作る → 候補一覧を保存
                                                                      ↓
                                                    人間が内容を確認して、手動でROOMに投稿
```

## 使う技術・仕組み

- 商品データの取得には、楽天が公式に提供している「楽天ウェブサービス（Rakuten Web Service）」の
  商品検索APIを使います。合言葉のような「アプリID」を無料で発行してもらう必要があります
  （発行方法は後日このREADMEに追記します）。
- プログラムはPython（プログラミング言語のひとつ）で作る予定です。

## フォルダ構成

```
.
├── README.md               このファイル
├── docs/
│   └── DESIGN.md           詳しい設計方針・調査結果
├── config/
│   └── settings.example.yaml   商品選定条件などの設定サンプル

├── requirements.txt          必要なPythonライブラリの一覧
├── data/
│   └── posted_items.json     過去に投稿した商品を記録しておくファイル（重複チェック用）
└── src/
    ├── main.py                 実行の入り口（このファイルを動かして候補一覧を作る）
    ├── rakuten_api.py          楽天ウェブサービスから商品データを取得する部分
    ├── filters.py              レビュー評価・件数などで商品を絞り込む部分
    ├── dedupe.py               過去の投稿と重複していないかチェックする部分
    ├── description_generator.py  紹介文を自動で組み立てる部分
    └── storage.py              候補一覧をファイルに保存・読み込みする部分
```

## セットアップ（準備）

1. Python がインストールされていない場合はインストールしてください（バージョン3.10以上を推奨）。
2. このリポジトリをダウンロード（クローン）します。
3. 必要なライブラリをインストールします。

   ```bash
   pip install -r requirements.txt
   ```

4. `.env.example` をコピーして `.env` という名前のファイルを作り、
   楽天ウェブサービスで発行した「アプリID」を書き込みます。

   ```bash
   cp .env.example .env
   ```

   `.env` ファイルは絶対にGitHubなどに公開しないでください（`.gitignore` で自動的に除外されます）。

5. `config/settings.example.yaml` を参考に、検索したいキーワードや条件を調整します。

## 大事な注意事項

- このプロジェクトは楽天ROOMへの**自動投稿を行いません**。生成された紹介文の最終確認と投稿は、
  必ず人間が行ってください。
- 楽天ウェブサービスの「アプリID」は個人情報に準じる大事な情報です。他人に教えたり、
  コードと一緒に公開したりしないでください。
- 楽天の利用規約は変更されることがあります。運用を始める前に、最新の
  [楽天ROOM利用規約](https://room.rakuten.co.jp/signup/agreement) を確認することをおすすめします。
